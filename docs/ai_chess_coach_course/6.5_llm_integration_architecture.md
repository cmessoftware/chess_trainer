> **Canonical course spec:** [06_5-ai_chess_coach_course_llm_coaching_recommendations.md](./06_5-ai_chess_coach_course_llm_coaching_recommendations.md)

The recommendation system must be designed to support multiple LLM providers.

The first implementation will use:

```text
google-genai SDK
+
Gemini 2.5 Flash
```

Future providers may include:

```text
Gemini
DeepSeek
OpenAI
Local Models
```

The rest of the ChessTrainer pipeline must remain provider-agnostic.

---

# LLM Provider Abstraction

Create:

```text
chess_trainer/llm/base.py
```

Define:

```python
from abc import ABC, abstractmethod

class LLMProvider(ABC):

    @abstractmethod
    def generate(self, prompt: str) -> str:
        pass
```

All providers must implement this interface.

---

# Gemini Provider

Create:

```text
chess_trainer/llm/gemini_provider.py
```

Implementation should use:

```python
from google import genai
```

and:

```python
client.models.generate_content(
    model="gemini-2.5-flash",
    contents=prompt
)
```

Example:

```python
from google import genai

class GeminiProvider(LLMProvider):

    def __init__(self, api_key: str):
        self.client = genai.Client(
            api_key=api_key
        )

    def generate(self, prompt: str) -> str:

        response = self.client.models.generate_content(
            model="gemini-2.5-flash",
            contents=prompt
        )

        return response.text
```

# Configuration

Create:

```text
chess_trainer/config/llm_settings.py
```

Example:

```python
from dataclasses import dataclass
import os

@dataclass
class LLMSettings:

    provider: str
    model: str
    api_key: str

settings = LLMSettings(
    provider="gemini",
    model="gemini-2.5-flash",
    api_key=os.getenv("GEMINI_API_KEY", "")
)
```

Environment variable:

```text
GEMINI_API_KEY
```

must be used.

Never hardcode API keys.

# LLM Factory

Create:

```text
chess_trainer/llm/provider_factory.py
```

Example:

```python
def create_provider(settings):

    if settings.provider == "gemini":
        return GeminiProvider(
            api_key=settings.api_key
        )

    raise ValueError(
        f"Unsupported provider: {settings.provider}"
    )
```

This will allow future support for:

```text
DeepSeekProvider
OpenAIProvider
LocalProvider
```

without changing the recommendation pipeline.

# Recommendation Generation Flow

The final recommendation flow should be:

```text
XGBoost
    ↓
SHAP
    ↓
Pattern Engine
    ↓
Player Pattern Aggregator
    ↓
Recommendation Context Builder
    ↓
Prompt Builder
    ↓
LLMProvider
    ↓
Coaching Recommendation
```

The LLM must never receive raw feature vectors.

The LLM must never receive full SHAP arrays.

The LLM receives only structured coaching context.

Example:

```json
{
  "player_elo": 1450,
  "dominant_patterns": [
    {
      "pattern": "unsafe_king",
      "count": 74
    },
    {
      "pattern": "undefended_piece",
      "count": 51
    }
  ],
  "trend": "stable",
  "top_openings": [
    "French Defense"
  ]
}
```

# Prompt Engineering Rules

The LLM prompt should focus on:

```text
coaching
education
improvement
training recommendations
```

The LLM should not invent facts.

The LLM should only use information present in the context payload.

The LLM should not discuss SHAP values.

The LLM should translate patterns into coaching advice.

Bad:

"king_safety contributed 0.42"

Good:

"Your king frequently remains exposed during the middlegame."
```

# Initial LLM Target

For Phase 1 of recommendations:

Use:

```text
Gemini 2.5 Flash
```

Reasoning:

- fast inference
- low operational complexity
- large context window
- sufficient reasoning quality
- low cost for prototyping

Do not optimize for local inference yet.

Do not implement local models during this phase.

Focus on validating:

```text
Pattern Engine
→ Context Builder
→ LLM Recommendations
```

before exploring local deployments.
